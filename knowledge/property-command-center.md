## The two live team tools

| Tool | Link | What it does |
|---|---|---|
| **Property Command Center** | https://claude.ai/artifact/4AMZxHejytEdUkP7zcDW7L | Shared board (monday-style) of every active property: health (On track / Needs action / Blocked / Needs update), closing date, blocker, checklist, tasks (owner / status / due / notes), notes with @-notify, public-record facts + comps. Shared with the org. Data lives in the artifact's database (`properties`, `tasks`, `notes` collections). Access issues go to Bryan ("Can interact" is needed to edit). |
| **Ask Juan** | https://claude.ai/artifact/Ke5zCdxvBJgRCQ5DqtvZD3 | Chat where team members ask "Juan" (an AI version trained on his voice and decision rules) and get an answer the way he'd give it. Supports photo/PDF/Word/Excel/text attachments. Chats and files stay in each person's browser and are never saved or shared. Built 2026-09-23. |

Board sections: **Disposition** (Pending to close = "money to collect" /
Under construction / Active, no buyer yet) and **Acquisition**. There is also
an "SF opportunity" (`watch`) type for San Francisco leads.
