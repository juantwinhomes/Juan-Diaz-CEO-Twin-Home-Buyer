# Deal / Comp Note Template — "Juan-Style"

> Standard format for all acquisition comp notes. Built to how Juan reads:
> verdict in the first 5 seconds, the deciding math right under it, detail below
> for drill-in. Origin: the 15742 Paseo Largavista note (Jul 2026), where a
> buried verdict + a number listed two ways ($725K vs $770K) nearly turned a
> live deal into a wrongful "pass."

## The five rules (Juan's read habits)

1. **Verdict on top.** Decision in one line; drill down only if you want.
2. **"The Gap" is the story.** Our number vs their number vs competition — that
   block IS the deal. Always second.
3. **One number, one place.** Each figure (esp. seller's target) lives in exactly
   ONE line. This is what breaks notes — same number written two ways.
4. **Ceiling is sacred.** Max-to-flip is labeled "do not exceed w/o approval."
   Ties to Juan's 85% rule.
5. **Flag contradictions out loud.** A dedicated ⚠️ line for "this doesn't add up."

## Template

```
🏠 [ADDRESS, CITY, ZIP] — comp run [DATE], by [NAME]

═══ VERDICT ═══
🟢 OFFER @ $___  /  🟡 WATCH  /  🔴 PASS
One line why: __________________________________

═══ THE GAP (the math that decides it) ═══
• Our max (to flip): $______   nets ~$____
• Their target:      $______   (cash as-is)  |  $______ (w/ agent)
• Competition:       $______   (other offer / agent)
• Gap:  we are  [ABOVE / BELOW]  their number by $____   → [DEAL / PASS]

═══ SELLER ═══
• Motivation: LOW / MED / HIGH — [why]
• Timeline: ____   • Reason moving: ____
• What they want: $____ cash as-is  |  $____ w/ agent   ← ONE source of truth
• Competing offers: ____

═══ SUBJECT ═══
• __bd/__ba · ~____sf · built ____ (type)
• Condition: ____
• Done recently: ____   • Needs: ____

═══ NUMBERS ═══
• ARV:  Low $____ / Mid $____ / High $____
• Rehab est: $____ (scope: ____)
• Wholesale offer: $____  → net ~$____
• Max-to-flip: $____  → net ~$____   (hard ceiling — do not exceed w/o approval)
• Profit calc: [link]

═══ COMPS ═══
• SOLD (3mo, 1mi): __ comps, $___k–$___k, DOM __
   Closest: [addr $__k, bd/ba, sf] ×3
• ACTIVE: __ ($___k–$___k)   • PENDING: __  (absorption __:1)
• Investor comp: $____   • Confidence: ____

═══ DATA CHECKS ═══
• Loan balance / equity: ____   • Title/liens: ____
• Transfer tax basis correct? ____  • ⚠️ Flags/contradictions: ____

═══ DECISION NEEDED ═══
• [What you need from Juan/approver, or "none — proceeding to offer @ $__"]
```

## Worked example — 15742 Paseo Largavista, San Lorenzo (Jul 10, 2026)

```
🏠 15742 Paseo Largavista, San Lorenzo, CA 94580 — comp run Jul 10, 2026

═══ VERDICT ═══
🟡 WATCH → likely 🟢 OFFER — CONFIRM HER CASH NUMBER FIRST
Why: if her cash target is $725K, our $732K max BEATS it — live deal, not a pass.

═══ THE GAP ═══
• Our max (to flip): $732,000  nets ~$50K
• Their target:      $725,000 cash as-is  |  $740–745K w/ agent
• Competition:       $740–745K (agent offer)
• Gap:  ABOVE her cash number by ~$7K  → DEAL (if $725K is real)
  ⚠️ Prior note said "$770K target" — unsupported. Resolve before acting.

═══ SELLER ═══
• Motivation: MEDIUM — engaged, comparing offers
• Timeline: ~60 days   • Reason moving: to daughter's
• What they want: $725K cash as-is  |  $740–745K w/ agent
• Competing offers: agent path $740–745K

═══ SUBJECT ═══
• 3bd/2ba · ~1,588sf · built 1944 (SFR)
• Condition: baths rough, kitchen needs a lot
• Done: new roof, ~5yr central A/C+heat, newer water heater  • Needs: kitchen + baths

═══ NUMBERS ═══
• ARV: Low $870K / Mid $930K / High $990K
• Rehab est: $65K (kitchen + baths; roof/HVAC done)
• Wholesale offer: $684K → net ~$100K
• Max-to-flip: $732K → net ~$50K  (hard ceiling — do not exceed w/o approval)
  Note: San Lorenzo unincorporated → county-rate transfer tax; true ceiling ~$6K higher
• Profit calc: [sheet link]

═══ COMPS ═══
• SOLD (3mo, 1mi): 40 comps; 3/2 ~1,500–1,670sf sold $820K–$980K, DOM 5–19
   Closest: 1603 Via Lacqua $900K (3/2,1,667sf) · 15879 Via Cordoba $820K (3/2,1,524sf) · 15781 Via Teresa $898K (3/2,1,471sf)
• ACTIVE: 5 ($699K–$995K)  • PENDING: 10  (absorption ~2:1)
• Investor comp: $668,548 (InvestorBase, 58 comps)  • Confidence: high, heavy investor area

═══ DATA CHECKS ═══
• Loan balance / equity: PropertyRadar not pulled — confirm
• Title/liens: TBD   • Transfer tax basis: default used, ceiling ~$6K higher
• ⚠️ Flags: her target listed two ways ($725K vs $770K) — resolve

═══ DECISION NEEDED ═══
• Confirm her real cash-as-is number. If $725K → write offer up to $732K. If $770K → pass.
```

**Lesson:** the rebuilt note turned a "pass" into a probable live deal — same data,
just the format forced the contradiction into the open.
