# Sample Property Color Decision — Small Green Ranch (July 2026)

Worked example of applying `2026-color-trends.md` to a real property photo.
Keep this format for future property color calls.

## Property read (fixed elements first)

- Small single-story ranch/bungalow, shingle siding, dated pale celery-mint
  green with white trim; street-facing garage with matching mint door.
- Light gray composition roof + warm gray concrete driveway → cool/neutral
  fixed elements → green-gray family over khaki/beige.
- Mature landscaping (boxwood hedges, lawn, weeping birch) → supports a green
  body color.
- Street comps: cream/brick house on one side, terracotta-orange on the other
  → muted sage differentiates without being the odd house out.
- Small footprint → mid-light body (small-house rule); deep tones door-only.

## Decision

| Element | Color | Rationale |
|---|---|---|
| Body/siding | Evergreen Fog SW 9130 | 2026 ranch sweet spot; suits gray roof + mature landscaping; modernizes existing green character |
| Trim/fascia | Alabaster SW 7008 | Creamy warm white, not stark |
| Garage door | Body color (Evergreen Fog) | Street-facing door must recede, not accent |
| Front door | Warm black / Urbane Bronze SW 7048 (alt: navy for resale data) | Single accent moment |
| Fixtures/numbers | Matte black | Current, ties to door |
| Picket fence | Fresh Alabaster or remove | Weathered fence drags the frontage |

Runner-up scheme: Universal Khaki SW 6150 body + Alabaster trim + black door
(max-safety neutral) — rejected here because the lot's landscaping and the
orange neighbor make the sage work harder.

## Reusable rules confirmed by this example

1. Street-facing garage doors get the body color, never an accent.
2. Mature landscaping → green family; bare lot → warm neutral.
3. Small house → mid-light body, accent saved for the door.
4. Always check both neighbors before committing a body color.
5. Note the free wins in every assessment (power-wash, fence paint, debris).
